## Publicar en GitHub Pages
1. Crea un repositorio público, por ejemplo `mi-portafolio`.
2. Sube el contenido de esta carpeta; `index.html` debe quedar en la raíz del repositorio.
3. Abre **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`, guarda y espera la publicación.

## Estructura
- `index.html`: contenido del portafolio.
- `css/styles.css`: estilos y diseño adaptable.
- `js/script.js`: menú móvil e interacciones.
- `img/`: fotografía y recursos gráficos.
